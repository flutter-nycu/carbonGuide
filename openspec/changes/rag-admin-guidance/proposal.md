# Explain RAG operations and outcomes

## Why
Administrators cannot tell what citation removal, chunk exclusion or unanswered interactions mean. Dense forms and technical details obscure the next safe action. The technical PDF needs plain-language explanations and a separate beginner manual.

## What Changes
- Explain draft versus saved changes, new chunk identities and required revalidation.
- Show saved refusal text and distinct missing, pending, failed, uncertain and expired outcomes without fabricating historical answers.
- Improve action readability, form spacing and progressive disclosure; provide contextual help on all seven pages.
- Publish expanded technical and beginner admin PDFs with reproducible sources.

## Impact
Frontend presentation and documentation only. Preserve backend authorization, billing, immutable data and publication gates. No model calls, content approval, cloud worker provisioning or Flutter integration.
