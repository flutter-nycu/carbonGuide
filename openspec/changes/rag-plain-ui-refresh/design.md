## 做法

- **上方列**：`Dashboard.tsx` 的 header 內含品牌、分頁 nav、帳號三塊，用 grid 排成一列；720px 以下改成兩列。桌面版 `position: sticky`。RAG 的 shadow root 透過繼承的 CSS 變數 `--rag-top` 知道上方列高度，側欄據此黏在上方列下面；本機預覽頁沒有上方列，變數不存在時為 0。
- **側欄收合**：`Workspace.tsx` 持有 `collapsed` 狀態，第一次讀 localStorage（`rag-sidebar-collapsed`），沒有紀錄時依視窗寬度決定；切換時寫回。所有 storage 存取包在 try/catch，讀不到就用預設值。收合時頁名仍在 DOM 裡（透明的提示框），按鈕的可讀名稱不變。
- **頁首按鈕**：每頁的頁首有一個按鈕位置，頁面用 `PageAction` 把主要按鈕 portal 進去，不必把按鈕狀態搬到外框。
- **圖示**：`rag/icons.tsx`，24×24 線條 SVG，只用 presentation attributes，不用 `style`，符合 `style-src 'self'`。
- **教學面板**：狀態初值從 localStorage（`rag-tutorial`）讀，id 不認得就丟掉；每次變更寫回。預設關閉。面板一律 fixed 浮在右下角，不再在寬螢幕佔一欄。
- **規格**：主規格「工作台頁面與上方分頁」寫死了舊頁名、編號，也禁止 01–10 頁出現導引；本 change 改寫該需求、加上側欄收合與操作教學，並更新其他提到舊頁名的需求。

## 風險

- 測試大量依畫面文字找元素，改名後要一起更新；以 type-check 與完整測試把關。
- localStorage 在私密模式或被封鎖時會丟例外：全部包 try/catch，畫面照預設值運作。
- 黏住的上方列與側欄依賴 CSS 變數穿過 shadow boundary；本機預覽與正式外框各驗一次。
