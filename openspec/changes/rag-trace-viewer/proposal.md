# RAG 歷史流程與成本檢視

## Why
測試專案已保存 40 筆本機評測追蹤，但工作台尚無可閱讀的流程或成本明細。管理者需要辨認每題真正執行、重用、略過及失敗的步驟。

## What Changes
- 互動紀錄加入 owner 專用的歷史追蹤列表、游標分頁及流程詳情，透過既有唯讀 RPC 讀取。
- 依序顯示節點、狀態、耗時、原因、模型用量及三種費用欄位。未知費用保留未知；重用步驟不重複計費。
- 桌面為橫向流程，手機為時間軸；提供鍵盤操作、錯誤重試、無資料及無權限狀態。
- 延續一般互動紀錄，排除已由追蹤列表呈現的匯入父紀錄。

## Impact
限網站 React 介面與唯讀資料存取。不變更權限、DB schema、模型服務、部署或產生新模型費用。即時試問、評測執行與完整分支追蹤仍屬後續階段。
