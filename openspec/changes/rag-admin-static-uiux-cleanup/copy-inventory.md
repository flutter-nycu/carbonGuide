## 子代理審查後採納的修正（摘要）

- 同一個詞不再有兩種意思：知識庫摘要卡「待處理」改成「還沒處理好」；評測狀態「待處理」改成「還沒通過」；System Prompt 和設定頁的徽章改成「下一版使用 p1／r1」。
- 版本號都加上名稱：版本紀錄寫成「提示詞 p1 · 檢索設定 r1」；互動紀錄表頭和詳情寫成「知識版本」「提示詞 / 檢索設定」。
- 追問電費時不再問「住哪個地區」（臺灣電價全國一樣）。
- 雙重否定「目前沒有還沒套用的草稿」改成「草稿和目前套用的內容一樣」。
- 全形句號後面不再多一個半形空格才接 [1]。
